Masarif — مصارف

Where the number goes

Masarif is a directory of organizations that distribute zakat, tagged by which of the eight classical categories (Surah At-Tawbah, 9:60) their work falls under. Miqyas doesn't process any payments — every entry routes to that organization's own donation page. The directory starts in Niagara, where it can be checked directly, and expands region by region as new organizations are verified.
